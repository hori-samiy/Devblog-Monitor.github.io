# Devblog-Monitor

Запуск: `pip install -r requirements.txt && python app.py` (или `gunicorn app:app`).

## Скриншоты
Кладите файлы `screenshots/server1/1.png`, `2.png`, `3.png` … (до 20 штук).
`serverN` — номер проекта по порядку в `servers.txt` (первая строка = server1).
Нумерация без пропусков: поиск идёт до первого отсутствующего файла.

## Отзывы
Работают через Flask (`app.py`), хранятся в `data/reviews.db`. Один отзыв с одного IP на проект
(повторный заменяет прежний). IP хранится только в виде хеша; задайте секрет: `REVIEW_SALT=...`.
Папка с базой: `DATA_DIR=/путь` (на хостинге лучше постоянный диск).
Отзывы не будут работать, если сайт лежит на статическом хостинге (GitHub Pages) без app.py.

## IP серверов
Кнопка копирования берёт `ip:port` из ответа API проекта (поля ip/port, connect, address).
